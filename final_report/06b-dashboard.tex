\section{The dashboard in use}
\label{sec:dashboard}

This section shows the running system through its browser clients. All screenshots in Figures~\ref{fig:dash-signedout}--\ref{fig:mobile} were captured on 14 November 2026 from the final code (\texttt{e13f019}) with Microsoft Edge driven by Playwright, using the synthetic users only. The phone pictures in Figures~\ref{fig:phone}--\ref{fig:phone-setup} come from the physical-phone run of 7 November (Section~\ref{sec:results}). The dashboard has three panels: \textbf{01 Session} (sign-in, the user's organizations and roles, refresh and sign-out), \textbf{02 Request} (the \code{X-Organization-ID} selector, one button per API call, and a verdict box that shows the HTTP status and the reason), and \textbf{03 Decision log} (the last ten requests).
