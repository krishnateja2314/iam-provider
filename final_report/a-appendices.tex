\section{Reproducing the results}
\label{app:repro}
With Docker Desktop and Node.js installed, from an empty directory:
\begin{verbatim}
git clone https://github.com/krishnateja2314/iam-provider
cd iam-provider
docker compose up -d --build --wait
\end{verbatim}
The web client is at \code{http://localhost:5173/web.html} and the mobile-style client at \code{http://localhost:5173/mobile.html}. Synthetic users: \code{alice / alice123} (admin at Acme, learner at Globex), \code{bob / bob123} (instructor at Acme), \code{enterprise.bob / enterprise-bob123} (through the enterprise broker).

\paragraph{Complete suite including the live provider.}
\begin{verbatim}
IAM_ALLOW_PASSWORD_GRANT_TESTS=true \
  node scripts/configure-keycloak.mjs --enable-test-client
docker compose exec -T backend env KEYCLOAK_INTROSPECTION=false \
  RUN_DATABASE_TESTS=1 RUN_KEYCLOAK_TESTS=1 npm test
node scripts/configure-keycloak.mjs          # disables the test client again
\end{verbatim}

\paragraph{The two agent outcome commands.}
\begin{verbatim}
docker compose exec -T backend env RUN_DATABASE_TESTS=1 RUN_KEYCLOAK_TESTS=1 \
  npx vitest run tests/security/service-principal.test.ts   # AG01: 30
docker compose exec -T backend env RUN_DATABASE_TESTS=1 RUN_KEYCLOAK_TESTS=1 \
  npx vitest run tests/security/delegation.test.ts          # AG02: 26
\end{verbatim}

\paragraph{Mutation runner, browser proof, latency.}
\begin{verbatim}
node scripts/verify-test-independence.mjs        # exit 0: all killed
npm --prefix backend ci                          # host packages for Playwright
IAM_BROWSER_CHANNEL=msedge node scripts/verify-pkce.mjs
docker compose exec -T backend node --input-type=module - \
  < scripts/measure-latency.mjs
\end{verbatim}

\paragraph{AG02 live demo.} Sign in to the web client as Alice, select Globex, press \code{POST /delegations}, copy the delegation ID, then:
\begin{verbatim}
node scripts/demo-delegation.mjs <delegation-id> \
  10000000-0000-0000-0000-000000000002
\end{verbatim}
\code{docs/demo-guide.md} has the full walkthrough, including the phone procedure.

\caption{HTTP API. ``tenant'' routes accept humans, AG01 agents and AG02 agents; ``human'' routes refuse agents with 403.}

\paragraph{Status codes.} 400 malformed input or tenant selector, or a delegation header on a human token; 401 invalid, expired, revoked or inactive credential, or an unknown, revoked or expired delegation; 403 no membership, grant or permission; 404 resource not in the selected tenant; 409 idempotency payload conflict; 503 provider, audit or authorization storage unavailable (never an allow).

\section{Glossary}
\begin{description}[leftmargin=3.2cm, labelwidth=3.0cm, itemsep=1pt]
  \item[Tenant] An organization using the platform (Acme, Globex); its data must stay separate.
  \item[Membership] A user's link to a tenant, with a status and roles in that tenant.
  \item[Principal] Anyone or anything that can call the API: a human user, an AG01 service principal or an AG02 delegated agent.
  \item[Introspection] Asking the identity provider whether a token is still active.
  \item[PKCE] Proof Key for Code Exchange: protects the login code of public clients.
  \item[Deny-overrides] A policy effect where any matching deny wins over any number of allows.
  \item[Hard boundary] A rule checked before the policy engine (tenant, ownership, published, teaching).
  \item[Mutation] A deliberate, single change that breaks one security guard, used to check that tests notice.
  \item[Killed / survived] A mutation is killed when the named tests fail with assertion errors; it survives when the tests still pass.
  \item[Clean clone] A fresh \code{git clone} started with new Docker volumes, so nothing from earlier runs is reused.
  \item[Delegation] A record that lets one agent act for one user in one tenant with a list of scopes until an expiry.
\end{description}
